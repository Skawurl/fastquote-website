Installation

Prerequisites

RequirementMinimumNotes
Python3.10+3.11 or 3.12 recommended
VS CodeAny recentWith the Python extension
openpyxl3.1+Only required dependency

Setup

  1. Clone the repository or download the latest release
  2. Create a virtual environment: python -m venv .venv
  3. Activate it: source .venv/bin/activate (Linux/macOS) or .venv\Scripts\Activate.ps1 (Windows)
  4. Install: pip install openpyxl

Verify

python -c "import openpyxl; print(openpyxl.__version__)"
python app/fastQuote.py template test.xlsx

If you see Template: test.xlsx you are ready.

Optional: VS Code Extension

Open the extension/ folder in VS Code, run npm install, then press F5 to launch. The extension provides a project tree view, inline Run / Validate buttons, and a config editor with JSON schema validation.

Optional: MCP Server

pip install "mcp[cli]" httpx
python mcp_server.py

Quick Start

# Generate a blank template workbook
python app/fastQuote.py template MyProject.xlsx

# Open in Excel or LibreOffice, fill in BOM data, save

# Process everything and generate all outputs
python app/fastQuote.py run MyProject.xlsx

The run command handles everything: BOM processing, BOQ generation, Quote sheet, Warnings, and vendor purchase orders.

Configuration

Generate a default config:

python app/fastQuote.py config

Key sections in bom_config.json: columns (1-based Excel positions), sheet_names, folder_types, settings (start row, max tree depth).

Estimator data (types, markups, rates, UOMs, vendors) lives in rates.csv — edit in Excel, then rates sync compiles to rates.json. Never hand-edit rates.json.

BOM Structure

Dot-notation item numbers define hierarchy. Folder types (ASSY, WELD) own children. Leaf types (PART, PROC, MATL, LABR) carry costs. Add new types in rates.csv — zero code changes.

Weight resolution: CAD mass, volume times density, or DXF profile area times thickness. Never guessed.

Pricing and Vendors

Provider chain (first non-empty wins): Price Book → Octopart → Digi-Key → McMaster → Grainger. Unpriced parts: your AI agent researches and records via price_book_upsert.

Rate Sheets

Shop economics in rates.csv: type, markup, injection, material ($/lb by grade), machining, welding, burn ($/in^2), coat ($/in^2), uom, header. Rate kinds: rate_per_lb, hrs_per_lb+rate_per_hr, pct_of_cost, rate_per_uom, rate_per_sqin, flat.

Drawing Takeoff

Four-layer Strategy Engine: Extract (AI reads drawing) → Normalize (Python to canonical CSV) → Match (Python to cost templates) → Compile (Python to BOM rows).

MCP Server

57 tools your AI agent can drive: BOM inspection, vendor pricing, price book, validation, rate sheets, pipeline, takeoff, strategy engine.

Validation

python app/fastQuote.py validate MyProject.xlsx. Checks missing prices, broken hierarchies, type consistency, rate drift. Severity-coded with row numbers and fix hints.
